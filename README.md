# Advanced Computer Networks: open course
Open `index.html` in a browser, or publish this folder with GitHub Pages. Offline material: `pdf/` (chapter PDFs, complete notes, reference cards) and `labs/` (runnable lab scripts and notebooks, Mininet labs).
Chatbot: a floating Ask-the-course button on every page and `chatbot.html`; it searches an index of the whole site (`assets/chatbot-data.js`, regenerated on every build) and runs fully in the browser with no server. RAG answers: retrieval picks the relevant passages and an AI model (in-browser WebGPU model, your cloud proxy in `worker/`, or any OpenAI-compatible endpoint such as Ollama) writes a cited answer from them; choose the mode with the AI mode button, or set the site default with `ACN_PROXY_URL=... python build.py` (see `worker/README.md`). Tests: `source/tests/README.md`.
Rebuild: `cd source && python build.py` (Python 3.12+; the PDF step needs `pip install weasyprint`, everything else is pure Python). Course text lives in `source/build.py` (core), `extra.py`, `deep.py`, `book1-5.py` (basics, advanced sections, labs), `appendix.py`; the chatbot in `book_chat.py`.
