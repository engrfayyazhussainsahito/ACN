Glossary

AIMD
Additive-increase, multiplicative-decrease window control.
ARQ
Automatic repeat request: retransmitting data until it is acknowledged.
All-reduce
Collective in which every participant ends up with the element-wise sum of all participants' data.
Anycast
Announcing one IP address from many locations so routing delivers each user to a nearby instance.
Autonomous system (AS)
A network under one administrative control that exchanges routes with others using BGP.
BDP
Bandwidth-delay product: data in flight to fill a path.
BGP
Border Gateway Protocol, the interdomain path-vector protocol.
Bufferbloat
Excess queueing delay from oversized buffers.
CDN
Content delivery network of distributed caches.
CIDR
Classless inter-domain routing: IP prefixes of any length written as address/length.
CSMA/CA
Carrier-sense multiple access with collision avoidance, the Wi-Fi medium-access method.
Chord
A distributed hash table that finds a key in O(log N) hops using finger tables.
Clos network
Multi-stage switching fabric with many equal-cost paths between ports; basis of fat-trees and leaf-spine.
CoDel
Queue-management algorithm that drops packets when minimum queueing delay stays above a target.
Congestion collapse
State in which load is high but useful throughput is very low because of retransmissions and drops.
Consistent hashing
Mapping keys to servers so that adding or removing a server moves only about 1/n of the keys.
DCTCP
Data-centre TCP: reduces the window in proportion to the fraction of ECN-marked packets.
DNSSEC
Signatures on DNS data so resolvers can verify authenticity and integrity.
DiffServ
IP quality-of-service architecture based on per-hop treatment of packet classes marked in the DSCP field.
ECMP
Equal-cost multipath: hash flows over equal-cost routes.
ECN
Explicit congestion notification: marks instead of drops.
FIB / RIB
Forwarding information base (used per packet) and routing information base (all learned routes).
Fat-tree
Clos-style data-centre topology built from identical k-port switches: k³/4 hosts, 5k²/4 switches.
Flowlet
A burst of packets of a flow separated from the next by an idle gap, used for order-safe load balancing.
Goodput
Application-level useful throughput, excluding headers and retransmissions.
HOL blocking
Head-of-line blocking: later data waits behind an earlier missing item in the same ordered stream or queue.
INT
In-band network telemetry: switches append measurements to packets as they pass.
Incast
Throughput collapse when many senders answer one receiver.
Jain's index
Fairness measure (Σx)²/(nΣx²), equal to 1 when all shares are equal.
Kendall notation
A/S/c/K description of a queue: arrival process, service process, servers, buffer.
LEO
Low Earth orbit, 500 to 2,000 km altitude; satellites move quickly and have short propagation delay.
LPM
Longest-prefix match: the rule of selecting the most specific matching route.
Little's law
L = λW.
MIMO
Multiple-input multiple-output: using several antennas to multiplex streams or steer beams.
MPLS
Multiprotocol label switching: forwarding by short labels along pre-established paths.
MSS
Maximum segment size: the largest TCP payload in one segment, typically 1460 bytes.
NAT
Network address translation: rewriting addresses and ports so private hosts share public addresses.
NFV
Network functions virtualisation: running firewalls, load balancers and similar functions as software.
OFDM
Orthogonal frequency-division multiplexing: many narrow subcarriers carrying symbols in parallel.
P4
Language for programming switch data planes.
PFC
Priority flow control: Ethernet pause frames that make a fabric lossless per traffic class.
PTO
Probe timeout: QUIC timer that triggers probe packets when no acknowledgment arrives.
QUIC
Encrypted, multiplexed transport over UDP.
QoE
Quality of experience: user-perceived quality, e.g. bitrate, stalls and start-up delay of video.
RDMA
Remote direct memory access: NIC-to-NIC memory transfers that bypass the host CPU and kernel.
RPKI
Public-key infrastructure that authenticates prefix origins.
Reflection attack
DDoS in which attackers spoof the victim's address so third-party servers send replies to the victim.
SDN
Software-defined networking: separate control and data planes.
SYN cookie
Stateless handshake defence encoding connection state in the server's initial sequence number.
Segment routing
Source routing in which the path is encoded as a list of segment identifiers in the packet.
Sketch
Small probabilistic summary of a data stream.
TCAM
Ternary content-addressable memory: hardware that matches rules with wildcard bits in one cycle.
TLS
Transport Layer Security: authenticated, encrypted channel protocol used by HTTPS.
Traffic engineering
Choosing routes and splits to balance load and meet performance goals.
Water-filling
Algorithm for max-min fair allocation: raise all rates equally until each is satisfied or capacity is exhausted.
Zipf's law
Popularity distribution in which the i-th most popular item has frequency proportional to i^(−α).
cwnd
Congestion window: sender's limit on unacknowledged data.
