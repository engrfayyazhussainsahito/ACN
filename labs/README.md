# Labs
Every week has a folder with `lab.py` (runs with plain Python 3.10+, no packages), `lab.ipynb` (the same code as a Jupyter notebook) and a README with the assignment. `mininet/` holds two emulation labs that need Linux, root and Mininet.

- `week01/`: Internet Architecture and Design Principles
- `week02/`: Queueing Theory and Performance Modelling
- `week03/`: Routing: Link-State, Distance-Vector and BGP
- `week04/`: Congestion Control I: AIMD, Reno and CUBIC
- `week05/`: Congestion Control II: BBR, Delay-Based and Modelling
- `week06/`: Modern Transport: QUIC, TLS 1.3 and Multipath
- `week07/`: Data Center Networks
- `week09/`: SDN and Programmable Data Planes
- `week10/`: Wireless and Mobile Networking
- `week11/`: Content Delivery and Video Streaming
- `week12/`: Network Security: DDoS, DNS, TLS and BGP
- `week13/`: Measurement, Satellite Networks and the Future
- `week14/`: AI Cluster Networking: RDMA, Collectives and Rail Design
- `week15/`: WAN Traffic Engineering, MPLS, Overlays and Naming
